# Code of Conduct

## Our Pledge

We are committed to providing a welcoming, respectful, and productive environment for everyone
involved in this research project.

## Standards

**Expected behaviour:**

- Use welcoming and inclusive language.
- Respect differing viewpoints and research approaches.
- Provide and accept constructive feedback.
- Show courtesy to all community members.
- Acknowledge uncertainty honestly.

**Unacceptable behaviour:**

- Harassment, discrimination, or derogatory language targeting any person or group.
- Using this project to stereotype or demean any cultural or linguistic community.
- Fabricating citations, data, or scientific claims.
- Claiming scientific authority that does not exist.
- Invasive or inappropriate personal conduct.

## Scope

This Code of Conduct applies within all project spaces including GitHub issues, pull requests,
discussions, and any communication channels associated with this project.

## Enforcement

Instances of unacceptable behaviour may be reported to the project maintainers.
Maintainers will review and respond to reports with appropriate action.
